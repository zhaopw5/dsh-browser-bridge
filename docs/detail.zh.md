# 浏览器采集器

Chrome、Edge 里的「DSH 抓页」扩展抓到的页面，从这里进入 DSH。

| 采集器 | 状态 | 说明 |
|---|---|---|
| Chrome | 已接入 | 运行时自动上报 `chrome` |
| Edge | 已接入 | 同一份扩展，自动上报 `edge` |

下面的开关决定放行哪些采集器。

---

**采集器目录**（只有这一份，不另存副本）：

```
~/.dsh/plugins/dsh-browser-bridge/collector
```

浏览器里用「加载已解压的扩展程序」指到这个目录。升级插件时文件原地更新，浏览器里点一次「重新加载」即可，路径不用改。

抓取会附加到**最近的会话**，回答前上下文里会出现「最近一次抓取」；模型也可以用 `browser_page` 工具直接取正文。
